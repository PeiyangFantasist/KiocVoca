# KiocVoca

面向 iPhone 的离线背词应用，沿用 OpenRT 的黑白、橙色与 Liquid Glass 设计。

- 乱序：左滑认识，右滑不认识；两种判断都显示词义，轻触卡片或“下一词”继续。
- 联想：84 个近义/相关语义组，随机组序与组内次序，每组最多连续 4 张；到期过久的词优先插入。
- 语义测试：简单英语四选一，提交后显示正确选项与中文释义。
- 统计：7 日记录、熟悉程度、每词累计/连续通过数、相对抽中权重、词库筛选、搜索、备份恢复。

词库以用户提供的三份 PDF **末尾索引**为完整性依据：200 + 179 + 244 = 623 条。派生词拆开、拼写变体合并后为 643 张卡。`data/coverage.json`逐条记录来源册数与原 PDF 页码。第 III 册的中文文字层损坏，中文释义重新整理。简单释义和语义组是面向练习的编辑内容，不表示所有相关词可在任何语境下互换。

## iPhone 安装

1. 用 Safari 打开 https://peiyangfantasist.github.io/KiocVoca/ 。
2. 下载 `KiocVoca.mobileconfig`。
3. 设置 → 通用 → VPN 与设备管理 → KiocVoca → 安装。描述文件未签名；只有一个 `com.apple.webClip.managed` 载荷，添加可移除的全屏网页图标。没有证书、VPN、MDM 或其他权限。
4. 从桌面图标联网打开一次，完成词库缓存。也可用 Safari“添加到主屏幕”。

这是 Web Clip / PWA，不是原生安装包。真实 iPhone 安装和设备语音需在设备上确认。Safari 和主屏幕应用可能使用不同的本机存储；最好始终从桌面图标使用。关闭应用后无需后台计时：返回时依据时间戳自动判断复习期限。应用不会在后台运行 JS，也不发送后台通知。

## 复习规则 KV-SR 1.0.0

每次正确回答或“认识”计一轮。连续通过 5、10、15…轮，基础抽中权重依次为 1/2、1/4、1/8…；每满 5 轮继续降低。失败清零连续轮次，恢复默认权重，保留累计记录。

最短间隔为 30 秒及 6 次其他回答，词库过小时自动缩短回答数要求。通过后的目标复习间隔按连续轮数指数增长、最多 7 天；失败目标 2 分钟。目标仅用于抽样优先级，仍允许通过最短冷却后提前复习。按熟悉层级设置 1–14 天硬期限，另设按词库规模的回答次数上限，超限优先抽取，防止熟词长期消失。硬期限优先于联想分组，仍遵守最短冷却。长期不打开应用无法主动提醒。

`seen`累计判断数；`passed`累计通过数；`streak`连续通过数；`failed`失败数。各模式共享记录，按模式另记次数。界面权重是相对基础权重，不是固定抽中概率。自评通过率与选择题分数不可视为严格同一考试指标，界面有说明。

## 保存与离线

学习记录存于 localStorage，保存失败会显示提示。词库、界面与描述文件用 Service Worker 缓存。无 AI、广告、分析追踪或外部词典请求；朗读使用设备语音。只保留最近 20,000 次事件明细，单词累计统计和每日汇总不截断。浏览器/系统可能清理存储，请定期导出 JSON 备份；导入前可先备份当前数据。

## 本地运行与验证

Node 20+；重新整理源数据需要 Python 3、PyMuPDF，生成图标和描述文件需要 Pillow。

```text
python tools/build-data.py
python tools/package.py
npm test
npm run serve
```

打开 http://127.0.0.1:5188 。纯静态 ES modules，无运行时第三方依赖。`tools/package.py`的 HTTPS URL 必须与部署地址一致。更新文件后重新运行生成 Service Worker 版本。改变算法须升级版本并迁移状态。

发布地址：https://peiyangfantasist.github.io/KiocVoca/ 。GitHub Pages 的工作流在每次推送后执行测试并部署 `dist`。脚本、样式和词库文件使用内容摘要作为文件名，避免离线缓存混用版本。

`engine.js`与页面解耦，随机源、时间均可注入做复现测试。`data/curation.txt`为人工编辑的简单释义/语义分组，`tools/build-data.py`在缺词、重复、缺中文释义、无效字符或覆盖不足时失败。
